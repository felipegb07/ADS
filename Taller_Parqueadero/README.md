# Taller Parqueadero

Este taller tiene la finalidad de hacer una correcta implementación de los FURPS+ y sus diferentes etapas peresentes en el proceso de diseño, haciendo que se puedan tener diferentes concepciones de los datos. Partiendo de un sistema de gestión de parqueaderos que permite hacer procesos más eficientes mediante distintas estrategias.

## Estructura
```txt
Elementos generales mediante txt
```

## Resumen del problema
Se plantea un problema que radica en un parqueadero, el cual debe ser administrado mediante un sistema de segmentación por pisos, haciendo que se haga la implementación de diferentes autores, casos de uso, requerimientos y conceptos. Se busca hacer un sistema eficiente que haga uso de nuevas tecnologías y variedad de opciones para el usuario que quiera acceder al servicio.

#### Actores presentes
- Conductor.
- Portero.
- Administrador.
- Dueño del parqueadero.

#### Requerimientos identificados

| Requerimiento | Tipo |
| --- | --- |
